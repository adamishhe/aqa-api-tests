# API-тестирование эндпоинта `/endpoint`

##  Описание

Проект содержит автотесты для проверки REST API эндпоинта `/endpoint`, который реализует следующий пользовательский сценарий:

* **LOGIN** — аутентификация по токену через внешний сервис `/auth`
* **ACTION** — выполнение действия через внешний сервис `/doAction`
* **LOGOUT** — завершение сессии и удаление токена из внутреннего хранилища

Тесты покрывают:

* позитивные пользовательские сценарии
* негативные сценарии
* ошибки внешнего сервиса
* валидацию формата токена

Внешние сервисы эмулируются с помощью **WireMock**.

## ️ Конфигурация

### WireMock

WireMock поднимается автоматически перед выполнением тестов:

* Старт: `@BeforeAll`
* Сброс состояния перед каждым тестом: `@BeforeEach`
* Остановка: `@AfterAll`

Все стабы настраиваются **явно в тестах**

##  Формат токена

* Длина: **32 символа**
* Допустимые символы: **0–9, A–F** 
* Примечание: в тз указано **0–9, A–Z** - неточность в требованиях

##  Тестовые случаи:

### Позитивные

* Успешный логин пользователя
* LOGIN → ACTION
* LOGIN → LOGOUT
* Полный цикл: LOGIN → ACTION → LOGOUT
* Повторный LOGIN с тем же токеном после LOGOUT
* Два пользователя работают параллельно

### Негативные

* ACTION без предварительного LOGIN
* Повторный LOGIN с тем же токеном
* ACTION после неуспешного LOGIN
* LOGOUT без предварительного LOGIN
* ACTION после LOGOUT 
* Повторный LOGOUT одного токена
* LOGIN с невалидным форматом токена

### Ошибки внешнего сервиса

* LOGIN при различных ошибках внешнего сервиса
* ACTION при различных ошибках внешнего сервиса
